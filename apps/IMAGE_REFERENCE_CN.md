# 参考图初始化（中文说明）

**New world** 与刷新页面使用相同的世界输入初始化逻辑：清空旧图片、图片描述和提示词，保留已保存的视角、模型、思考等级、步数及种子设置。两种操作都会中止旧页面的生成/回滚轮询并请求释放对应会话，迟到的结果不会影响新 World。浏览器后退缓存恢复也会返回空白设置页。刷新时通过 keepalive 请求释放；若浏览器或网络未能送达，仍由服务端过期机制兜底。

在 **Perspective** 旁点击 **Upload image**，选择图片后自动进入参考图界面，由 Nomas-PE 生成描述。输入 **User prompt** 后点击 **Enter world**。移除图片会返回文字模式并恢复草稿。

- 内部参考段为 **5 秒**：24 FPS 下编码 120 个像素帧，得到 30 个 latent frames，完整写入 DiT 的 **KV cache**，并保留 PixelUMM 时序状态。
- 初始化期间显示 **Loading image reference into KV cache…**
- 视频只保留参考段最后 **0.5 秒（12 帧）**，标记为 **T0-Reference Image**；其余 4.5 秒不进入播放和下载视频。
- 随后自动生成用户提示词段，标记为 **T1 · TEXT**，从播放时间 **0.5 秒**开始；后续继续 T2、T3。
- 后续解码可修正 T0 的已显示尾帧，但不会把被裁掉的参考帧重新拼回视频。
- PE 仍按内部五秒参考时间线理解历史；播放时间线从 T0 的半秒视频开始。

默认提示增强模型为 Nomas-PE，思考模式为 None；可选择已配置的 Kimi-K3 和其他思考等级。
启动配置见 [部署说明](README.md)。更改后需重启网关和 GPU worker，并新建 World；旧视频不自动修改。
