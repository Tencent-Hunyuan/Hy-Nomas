# B300 Four-GPU Inference

One entry point: scripts/inference/inference_b300_sp4.py. Supply your own
input JSON; no prompt sample is bundled. The JSON must follow the pipeline's
inference schema, including prompts and segment_frame_boundaries.

```bash
.venv-inference/bin/python scripts/inference/inference_b300_sp4.py \
  /absolute/path/input.json --gpus 0,1,2,3 --output outputs/b300_sp4
```

The script launches four ranks itself. All segments are generated by default;
use --segments N to select the first N segments. Model/config overrides can
be appended as Hydra key=value arguments. Output includes results.json,
per-rank stage logs and run1/video.mp4 (24 fps).

## Execution

- Load DiT, text encoder and VAE weights onto GPU before timing.
- Use Magi attention, VAE DeepGEMM FP8, SM103 CuTe fusion and torch.compile.
- Retain the complete K/V archive on GPU; attention selects 36 past frames.
- Run one full warmup, then a measured request with fresh GPU history.
- Decode VAE once after all segments; explicitly release request history.
- GPU E2E excludes startup, warmup, validation and video export. MP4 latency
  includes conversion, final output D2H and encoding.

Dependencies: Python 3.12, PyTorch 2.10.0+cu130, MagiAttention
1.1.6.post11+g8472cf27, DeepGEMM 2.1.1+local, CUTLASS DSL 4.8.0.
Expected checkpoints are under weights/Hy-Nomas and weights/Qwen2.5-VL-7B-Instruct.
CUDA_HOME defaults to vendor/cuda; override it for another toolkit location.
Set NCCL_SOCKET_IFNAME if a specific network interface is needed.
System CUDA is not modified. Dependencies/weights/media are not committed.

## Recorded Benchmark

Measured 2026-11-02 on four B300 GPUs with six segments: 1502 frames,
1280 x 704, eight Euler steps per segment, CFG 1, seed 42.
These results precede entry-point consolidation; they are not a new timing.

| Measurement | Seconds | Generated fps |
| --- | ---: | ---: |
| Warmed GPU E2E | 47.022 | 31.943 |
| Warmed request to MP4 | 57.435 | 26.151 |
| Cold full warmup | 66.201 | 22.688 |

Warmed breakdown: DiT 33.055 s, cache 5.140 s, VAE 8.167 s,
text 0.183 s, remaining 0.476 s. Both warmed rates exceed 24 fps;
this is one request, not a general or serving throughput guarantee.
Measured ranks had no new Dynamo compilation or K/V payload H2D/D2H.
Peak PyTorch allocation: rank 0 81.010 GiB, others 73.236 GiB.
Shared GPUs had about 104 GiB free; previous SP1/SP2 attempts OOMed.
Some older audit labels say cpu_archive even for GPU storage.

Focused history, Magi, SM103 and DeepGEMM tests passed before their scratch
scripts were removed from this branch. Raw historical results and video remain
on the benchmark host in outputs/e2e_sp4_gpu_history_6segments_20261102/.
